💸 Site Tio Meio Rico
Um site simples, divertido e com um toque irônico — porque ser rico de verdade talvez não dê, mas ser meio rico... a gente tenta 😎

🧾 Sobre o projeto
Este é um site feito com HTML puro, com foco em conteúdo estático e estilo descontraído.
Foi desenvolvido como experimento criativo, educacional e, claro, com um pouquinho de sarcasmo digital.
